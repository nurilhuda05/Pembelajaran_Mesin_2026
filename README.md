# Pembelajaran Mesin 2026

Repositori ini berisi tugas dan praktikum mata kuliah **Pembelajaran Mesin 2026** menggunakan dataset PBL perumahan Jakarta (`Data/jakarta_house.csv`).

---

## Catatan Jobsheet 6 ANN 

Praktikum **Jobsheet 6 ANN** dijalankan di **Google Colab** (bukan di lokal/laptop) karena:

1. **Library ScaNN tidak bisa di Windows:**
   Salah satu algoritma yang digunakan yaitu **Google ScaNN** hanya mendukung sistem operasi **Linux**. Karena laptop lokal menggunakan Windows, instalasi ScaNN akan gagal/error.
2. **Google Colab menggunakan Linux:**
   Google Colab sudah berbasis sistem Linux, sehingga library **ScaNN**, **FAISS**, dan **Annoy** bisa langsung diinstal dan berjalan normal tanpa kendala.
